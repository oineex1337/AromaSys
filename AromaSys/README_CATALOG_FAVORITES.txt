AromaSys: каталог и избранное

Что добавлено
- ORM-модели брендов, парфюмерии, SKU, остатков и избранного.
- GET /catalog, поиск по названию и бренду, фильтр по gender.
- GET /favorites/<user_id>.
- POST /favorites.
- DELETE /favorites/<user_id>/<sku_id>.
- API авторизации возвращает user_id.
- Экран каталога и экран избранного в Kivy.

1. Подготовка базы
Таблица favorites должна быть создана. В твоей базе она уже создана.
Чтобы добавить демонстрационные товары, открой pgAdmin, выбери базу AromaSys,
открой Query Tool, загрузи backend/seed_demo.sql и выполни его один раз.

2. Настройка подключения
Открой backend/database.py и проверь DB_USER, DB_PASSWORD, DB_HOST, DB_PORT, DB_NAME.
Не публикуй этот файл с настоящим паролем от базы данных.

3. Установка backend-зависимостей
Открой терминал VS Code в папке backend и выполни:
py -m pip install -r requirements.txt

4. Запуск Flask
В папке backend выполни:
py app.py
Оставь это окно терминала открытым.
Проверь в браузере http://127.0.0.1:5000/health . Ожидаемый ответ:
{"status":"ok","database":"ok"}

5. Запуск Kivy
Открой второй терминал в папке mobile и выполни:
py -m pip install requests kivy
py main.py

Для запуска приложения и Flask на одном компьютере API_URL оставь http://127.0.0.1:5000.
Если приложение запускается на телефоне, 127.0.0.1 указывает на сам телефон.
Тогда укажи в mobile/main.py локальный IP компьютера в сети Wi-Fi, например
http://192.168.1.10:5000, и настрой доступ к порту 5000 в брандмауэре.

Проверка API
GET http://127.0.0.1:5000/catalog
GET http://127.0.0.1:5000/favorites/1

Добавление в избранное требует существующих user_id и sku_id:
POST http://127.0.0.1:5000/favorites
JSON: {"user_id": 1, "sku_id": 1}

Удаление:
DELETE http://127.0.0.1:5000/favorites/1/1

Примечание по безопасности
В текущем учебном варианте API принимает user_id от клиента. Перед реальным запуском
нужна авторизация по токену, иначе пользователь сможет подставить чужой user_id.


Настройка владельца каталога (новая правка)
Открой mobile/admin_config.py. В строке ADMIN_EMAIL укажи email аккаунта, который
должен добавлять, редактировать и удалять парфюмерию. Укажи email точно так же,
как он записан в аккаунте. Все остальные аккаунты смогут просматривать каталог
и добавлять товары в избранное, но не увидят кнопки управления каталогом.

Кнопка «ГЛАВНАЯ» находится в верхней панели авторизованных экранов. Выход из
аккаунта находится в профиле. Имя пользователя и email в редактировании профиля
недоступны для изменения, редактируется адрес доставки.

Ограничение владельца реализовано в мобильном интерфейсе. Пока не добавлена
проверка прав на стороне Flask API, это не является полноценной серверной защитой.
Для промышленного использования и следующего этапа проекта роль администратора
нужно проверять на сервере для каждого изменяющего запроса.
